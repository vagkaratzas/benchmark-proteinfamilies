benchmark-proteinfamilies

Sample manually curated InterPro families, then measure how well any protein-family generation tool reconstructs them. This page is the map: what each station does, why it exists, and which artefacts tie the three phases together. It is teaching material for the pipeline — it does not track any real run.

Running it

# 1. build the universe (once)
nextflow run benchmark-proteinfamilies --workflow_mode pre --outdir results -profile singularity

# 2. run whatever tool you are benchmarking on results/pre/combined_decoy.faa

# 3. score the tool runs listed in your samplesheet
nextflow run benchmark-proteinfamilies -c post.config --workflow_mode post -profile singularity
